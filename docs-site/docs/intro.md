# Introduction

Welcome to **SlicePizza**: a hands-on DevOps learning project built around an
online ordering system for a fictional pizzeria, **Zé's Pizzeria**.

The system starts small and grows in phases. In each phase, the "pizzeria owner"
asks for something new, and that request forces you to learn a new technology:
Docker, DNS, cloud, queues, CI/CD, observability, Terraform and Kubernetes.

> The idea is to **feel the problem before using the tool**.

## What you will find here

- **Phase guides** — what Zé asked for and how the system evolves to meet it.
- **Technical notes** — how the API, the database and the Docker stack fit together.
- **ADRs** — architecture decision records explaining why each choice was made.

Start with [Phase 1 overview](./phase-1/overview.md).
